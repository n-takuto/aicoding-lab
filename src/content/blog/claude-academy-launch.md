以前このブログで「[Anthropic AcademyのClaude Code 101を受けた感想](/blog/anthropic-academy-claude-code-101/)」「[Anthropic AcademyのClaude Platform 101を受けた感想](/blog/anthropic-academy-claude-platform-101/)」という記事を書きました。あの**Anthropic Academyが、いつの間にか「Claude Academy」に生まれ変わっていました**。しかも日本語対応まで始まっています。

自分が受けたサイトがどう変わったのか気になったので、実際に確認してきました。

## 何が変わった？名称・URL・規模の変化

まず全体像を整理します。

| 項目 | 旧：Anthropic Academy | 新：Claude Academy |
|------|----------------------|---------------------|
| URL | `anthropic.com/learn`（実体は`anthropic.skilljar.com`） | `academy.claude.com` |
| 開始時期 | 2026年3月2日 | 2026年8月20日頃 |
| 提供形態 | 外部の学習管理システム（Skilljar）上で運営 | Claude専用の独立サイト |
| コース数 | 13コース | 数十コース＋大量のチュートリアル・ユースケース（後述） |
| 言語 | 英語のみ | 英語＋日本語（一部）ほか |

`anthropic.com/learn`にアクセスすると、**2026年8月29日確認時点で自動的に`academy.claude.com`に転送されます**。旧サイト（`anthropic.skilljar.com`）自体はまだログイン画面が残っていますが、コンテンツの主戦場は完全に新サイトに移っています。

## コース数が大幅に増えた

実際に新サイトの「すべてのリソース」ページを開いてみると、**373件のリソース**（コース・チュートリアル・ユースケース・ウェビナーの合計）が表示されました。

コースだけに絞っても、以前の13コースから大きく増えていて、Claude.ai・Claude Cowork・Claude Code・Claude Platform・Claude Tagという5つの製品カテゴリに加えて、「AI Fluency」という**AIとの協働スキルそのものを学ぶ**新カテゴリが追加されていました。「ビルダーのためのAI Fluency」「教育者のためのAI Fluency」「中小企業のためのAI Fluency」など、職種・立場別のコースまで用意されています。

以前このブログで受講した「Claude Code 101」「Claude Platform 101」も、そのままの名前で健在でした。さらに「実践Claude Code」という、開発ワークフローへの組み込みに寄せた新しいコースも追加されています。

## 日本語対応、ただし一部は未翻訳

今回の一番の変化がこれです。新サイトには`/ja`という日本語版のパスがあり、実際に開くとトップページの文言（「Claude Academy へようこそ」等）や、多くのコース説明が日本語化されていました。

ただし、**全部が日本語というわけではありません**。実際にコース一覧を確認したところ、こんな状態でした。

| コース例 | 状態 |
|---------|------|
| AI活用力：フレームワーク&基礎 | 日本語化済み |
| Claude 101 / Claude Code 101 | 日本語化済み |
| Claude Platform 101 | **説明文が英語のまま** |
| Deploying Claude Enterprise with Confidence | **タイトル・説明とも英語のまま** |

開発者向け・エンタープライズ向けの一部コースは、まだ翻訳が追いついていない状態です。日本語対応は始まったばかりで、順次拡充されていく段階だと考えられます。

## コンテンツはログイン不要、進捗管理だけログインが必要

もう1つ確認できたのが、**コース本体の閲覧にはログインが不要**という点です。ログインするのは、受講の進捗を記録したり、コース修了時にもらえるバッジ（LinkedInのプロフィールに追加できるもの）を受け取りたい場合だけでした。以前のSkilljarベースのサイトより、気軽に覗きに行きやすくなっています。

## まとめ

- 無料学習サイト「Anthropic Academy」が「Claude Academy」（`academy.claude.com`）に刷新された（2026年8月20日頃）
- 旧URL（`anthropic.com/learn`）は新サイトに自動転送される
- コースが13から大幅に増加、「AI Fluency」という新カテゴリも追加
- 日本語対応が始まったが、Claude Platform 101など一部コースはまだ英語のまま（翻訳は発展途上）
- コース閲覧はログイン不要、進捗管理・修了バッジ取得のみログインが必要

以前受けた3コース（Claude 101、Claude Code 101、Claude Platform 101）は、CCA-F試験対策としても実用的な内容でした。日本語対応が進めば、英語が苦手な人にとってさらに入りやすいサイトになりそうです。
