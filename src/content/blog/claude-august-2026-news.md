2026年8月に入って、Claude・Claude Code関連でいくつか動きがありました。特に**今まさに恩恵を受けられる話**があるので、公式情報をもとにまとめます。

## ① Claude Codeの週次利用上限、+50%が8月19日まで延長中

一番実利があるのがこれです。**Pro / Max / Team / 一部Enterpriseプランのユーザーは、何もしなくても週次の利用上限が通常の1.5倍になっています。**

- 対象：Pro、Max、Team、座席ベースのEnterpriseプラン
- 対象外：無料プラン、従量課金のEnterprise
- 適用範囲：CLI・IDE拡張・デスクトップアプリ・Web版すべてのClaude Code
- 申請不要、該当プランなら自動適用
- 期限：**2026年8月19日まで**（Anthropic公式アカウントが延長を発表）

> ⚠️ この情報の一次情報は、Anthropic公式ヘルプページではなく[公式X（@ClaudeDevs）の投稿](https://x.com/ClaudeDevs/status/2078511173759324328)です。期限は今後さらに延長・変更される可能性があるので、大きめのタスクを投げる前に一応最新情報を確認してください。

普段より重めのタスクを試すなら、今週中がお得です。

## ② Claude Code自体もアップデートしてる

[公式changelog](https://code.claude.com/docs/en/changelog)によると、2026年8月4日リリースのバージョン2.1.222で、いくつか実用的な変更が入っています。

| 変更内容 | どんなもの？ |
|---------|------------|
| **Focus view**（VSCode） | ツールの実行ログを折りたたんでサマリー表示にできる新しい表示モード。`Ctrl+Alt+F`で切り替え |
| **サンドボックスの認証情報マスキング** | Linux/WSLで、サンドボックス内のコマンドに実際の認証情報を渡さず、ダミー値に差し替えられる機能 |
| **Windows起動の高速化** | プロセス作成をPowerShell経由からネイティブのkernel32呼び出しに変更。エンドポイント保護ソフトでPowerShellがブロックされてる環境でも起動できるように |
| セキュリティ修正 | Zshの`[[ ]]`条件内でコマンドが隠れて実行されてしまう脆弱性などを修正 |

Windowsユーザーとしては、起動まわりの改善はありがたいところです。

## ③ Sonnet 5の導入価格、8月31日で終了

6月30日に登場したClaude Sonnet 5は、**2026年8月31日まで入力$2 / 出力$10という導入価格**で使えます。9月1日からは通常価格の入力$3 / 出力$15に戻ります（[公式モデル比較表](https://platform.claude.com/docs/en/about-claude/models/overview)より）。

API経由でSonnet 5を試すつもりなら、9月になる前に触っておくとコストを抑えられます。

## ④ MCPの仕様が変わった（開発者向け）

**MCP（Model Context Protocol）** は、ClaudeのようなAIと外部サービス（Slack・データベース・検索など）を繋ぐための共通規格です。自分でMCPサーバーを作ってる人向けの話ですが、7月28日付でこのMCPの仕様が更新されました。ざっくり言うと、**「接続を維持し続ける双方向のやり取り」から「毎回リクエストとレスポンスだけで完結する」設計に変わった**、というのが今回の大きな変更です（[公式ブログ](https://blog.modelcontextprotocol.io/posts/2026-07-28/)より）。

最初に接続を確立する`initialize`のやり取りが廃止されました。セッションを識別する`Mcp-Session-Id`というヘッダーも廃止され、リクエストごとに必要な情報を全部含める形になりました。サーバー側で会話の状態を覚えておく必要がなくなるので、普通のロードバランサーで複数台に処理を振り分けやすくなる、というメリットがあるそうです。

このブログでも[Brave Search MCPの記事](/blog/brave-search-mcp/)で軽く触れましたが、自分でMCPサーバーを作る予定がなければ、当面は「へえ」くらいで大丈夫です。

## まとめ

- **Claude Codeの週次利用上限+50%が8月19日まで延長中**（Pro/Max/Team対象、申請不要）
- Claude Code 2.1.222（8月4日）でFocus view・サンドボックス認証情報マスキング・Windows起動の高速化などが追加
- Sonnet 5の導入価格（$2/$10）は8月31日まで、9月からは通常の$3/$15
- MCPの仕様が7月28日付でステートレス設計に変更（開発者向け）

利用上限の延長は今週までなので、気になってたタスクがあれば試すなら今のうちです。
