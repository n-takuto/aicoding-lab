2026年7月24日、Anthropicが新モデル **「Claude Opus 5」** をリリースしました。6月30日のSonnet 5登場から、わずか3週間ちょっとでの新モデル投入です。

「Opus 4.8と何が違うの？」「Sonnet 5とどう使い分ければいい？」というところ、公式情報をもとに整理しました。

## Claude Opus 5の基本スペック

まずは基本情報から。[Anthropic公式発表](https://www.anthropic.com/news/claude-opus-5)と[公式モデル比較表](https://platform.claude.com/docs/en/about-claude/models/overview)で確認した内容です。

| 項目 | 内容 |
|------|------|
| リリース日 | 2026年7月24日 |
| APIモデル名 | `claude-opus-5` |
| 料金（100万トークンあたり） | 入力$5 / 出力$25（**Opus 4.8と同額**） |
| コンテキストウィンドウ（※1回にやり取りできる文章量） | 100万トークン |
| 最大出力 | 128,000トークン |
| 信頼できる知識カットオフ | 2026年5月 |
| 利用できる場所 | Claude API、Claude.ai、Claude Code、Claude Cowork、全プラットフォーム |

公式の位置づけは「複雑なエージェント型コーディングとエンタープライズ業務向け」。料金はOpus 4.8と完全に同額で、価格そのままに性能だけ上がった**ドロップイン・アップグレード**（設定を変えずにそのまま入れ替えられるアップグレード）という扱いです。

## Opus 4.8から何が良くなった？

公式発表に載っていたベンチマーク数値です。

| ベンチマーク | 結果 |
|------------|------|
| Frontier-Bench（ソフトウェアエンジニアリング） | Opus 4.8の2倍超のスコア |
| ARC-AGI 3（問題解決） | 次点モデルの3倍のスコア |
| Zapier AutomationBench | 次点モデルの約1.5倍の合格率（同コストで） |
| 有機化学タスク | Opus 4.8比 +10.2ポイント |
| CursorBench（最大努力設定） | Fable 5のピークスコアの0.5%以内、コストは半分 |
| OSWorld 2.0（コンピュータ操作） | Fable 5の最高結果を上回る、コストは約1/3 |

Box社が実業務で検証した結果も公開されていて、データ分析で+11%、デューデリジェンス業務で+17%の改善が出たとのことです。

数字だけだと分かりにくいですが、要は「**Fable 5に迫る性能を、Opus 4.8と同じ価格で**」というのが今回の売りです。

## Sonnet 5とはどう使い分ける？

2026年7月26日時点、Claude Platformには Fable 5・Opus 5・Sonnet 5・Haiku 4.5の4モデルが並んでいます。公式ドキュメントには、こんな使い分けの指針が書かれています。

> 迷ったらOpus 5から始めてください（複雑なエージェント型コーディング・エンタープライズ業務向け）。最高性能が必要ならFable 5を使ってください。

比較表の説明欄はもっと簡潔です。

| モデル | 位置づけ（公式） | 料金（入力/出力・100万トークン） |
|--------|----------------|--------------------------------|
| Fable 5 | 最も高性能（長時間稼働のエージェント向け） | $10 / $50 |
| **Opus 5** | 複雑なエージェント型コーディング・エンタープライズ業務向け | $5 / $25 |
| Sonnet 5 | 速度と知性のベストバランス | $3 / $15（〜2026年8月31日は$2 / $10の導入価格） |
| Haiku 4.5 | 近フロンティア性能かつ最速 | $1 / $5 |

知識カットオフにも差があって、**Opus 5だけ2026年5月と一番新しく**、Sonnet 5は2026年1月のままです。最新の出来事について聞きたいタスクなら、この差も判断材料になります。

ざっくりまとめると、日常的なコーディングや記事執筆はSonnet 5で十分、複雑な設計や大規模なエージェントタスクにはOpus 5、というのがこれまでの「Opus/Sonnet/Haiku」の使い分けと同じ感覚で通用します。

## Opus 4.8は使えなくなる？

廃止予定の記載はありませんでした。それどころか、Claude.ai・Claude Code・Claude Coworkでは、**セーフティ上フラグが立ったリクエストのフォールバックモデル**（危険性が疑われる操作を検知した際に自動で切り替わる代替モデル）**として、今後もOpus 4.8が使われ続ける**と明記されています。しばらくは併存する形です。

## Claude Codeで試してみる

Claude Codeでの切り替え方は、これまでのモデル切り替えと同じです。

```
/model claude-opus-5
```

デスクトップ版なら、画面下部のモデル名をクリックしてメニューから選ぶだけです。詳しい切り替え手順は[こちらの記事](/blog/claude-code-token-tips/)にまとめています。

## まとめ

- 2026年7月24日、Claude Opus 5がリリースされた（Sonnet 5から約3週間後）
- 料金はOpus 4.8と同額（入力$5・出力$25）で、性能はFable 5に迫る水準まで向上
- 公式の位置づけは「複雑なエージェント型コーディング・エンタープライズ業務向け」
- Sonnet 5は「速度と知性のバランス」、日常タスクはSonnet 5、複雑な作業はOpus 5という使い分けが基本
- Opus 4.8は廃止されず、セーフティ用フォールバックとして併存
